# ソフト・依存関係の安全な扱い（SW01）

不明なソフト、出所不明のバイナリ/スクリプト、未知URLからのdownload/install/実行は行いません。短縮URL、検索上位、AIの推薦、一般的な作業承認だけで安全と判断しません。

既存依存を扱う場合は、repo固有のpackage managerとlockfile、採用済み提供元・registry、固定版、取得物の検証方法、install/postinstall等の実行script、要求権限、外部送信と費用を必要範囲で確認します。認証設定や秘密値は開きません。

既存規則で許可され、必要情報・実権限・0円条件が確認できる通常の依存再現は、既存のsandboxと制御の範囲で進められます。新規ソフトの導入、MCP/拡張追加、管理者権限、本番環境への導入は、候補・必要性・公式根拠・差分・復元を杉本へ渡します。

`curl ... | sh` 等、取得と即実行をつなぐ手段で検査を省略しません。未知のものを試すために本番資格・実データ・秘密を持つ環境を使いません。既存CIが依存取得する場合も、その設定を今回の設定ファイル配布で勝手に変更しません。

安全性を確認できない依存操作だけ保留し、設計、コード候補、合成データ、既存の利用可能なツールによる検証を先に進めます。
